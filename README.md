# Mini Version Control System

A console-based version control system developed in C++ as a university assignment.

## Features

- Initialize a repository
- Add and track files
- Create commits
- Create and switch branches
- Display files in the current commit
- Compare branches using diff
- View commit history and commit graph
- Display object statistics

## Concepts Used

- Object-Oriented Programming
- Classes and objects
- Constructors and destructors
- Copy constructors and deep copying
- Dynamic memory allocation
- Pointers and arrays
- C-style string handling

## How to Run

Compile `main.cpp` using a C++ compiler and run the generated executable.

## Commands

`init`, `add`, `commit`, `branch`, `checkout`, `show`, `diff`, `log`, `graph`, `stats`, `exit`

This project is a simplified educational implementation inspired by version control systems.
